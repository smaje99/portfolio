## A grouped educational evidence set

This project groups related exercises and projects from a data structures course. Its purpose is to show applied learning through implementations from scratch, use of the Java API, guided exercises, and tests.

The set includes abstract data types, recursion, sorting simulators, and a calculator for infix-to-postfix expressions. It is presented as secondary evidence of fundamentals, logical modeling, and problem solving—not as an operational product or an end-user solution.

## Public repositories

[`ds-tdd-uniamazonia`](https://github.com/smaje99/ds-tdd-uniamazonia) is the main reference because it combines guided exercises, contract tests, and a reusable pedagogical structure. The set also includes [`sorting-comparator`](https://github.com/smaje99/sorting-comparator), [`SimuladorTDA`](https://github.com/smaje99/SimuladorTDA), and [`Calc2`](https://github.com/smaje99/Calc2).

## Status and learning

The project retains its **prototype** status. The repositories were developed by Sergio and are linked as public evidence of implementation, testing, and deliberate practice, without adding dates, academic context, or usage outcomes that are not documented.
