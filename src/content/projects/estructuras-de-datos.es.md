## Una evidencia educativa agrupada

Este proyecto reúne ejercicios y proyectos relacionados de un curso de estructuras de datos. Su propósito es mostrar aprendizaje aplicado mediante implementaciones desde cero, uso de la API de Java, ejercicios con retroalimentación y pruebas.

El conjunto incluye tipos de datos abstractos, recursividad, simuladores de ordenamiento y una calculadora de expresiones infijas a postfijas. Se presenta como evidencia secundaria de fundamentos, modelado lógico y resolución de problemas; no como producto operativo ni como solución para usuarios finales.

## Repositorios públicos

[`ds-tdd-uniamazonia`](https://github.com/smaje99/ds-tdd-uniamazonia) es la referencia principal por integrar ejercicios guiados, pruebas de contrato y una estructura pedagógica reutilizable. También forman parte del conjunto [`sorting-comparator`](https://github.com/smaje99/sorting-comparator), [`SimuladorTDA`](https://github.com/smaje99/SimuladorTDA) y [`Calc2`](https://github.com/smaje99/Calc2).

## Estado y aprendizaje

El proyecto conserva el estado **prototipo**. Los repositorios fueron desarrollados por Sergio y se enlazan como evidencia pública de implementación, pruebas y práctica deliberada, sin añadir fechas, contexto académico o resultados de uso que no estén documentados.
